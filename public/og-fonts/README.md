# OG-image fonts

Static TTF instances used by `lib/og.tsx` inside `ImageResponse` (Satori can't
consume variable fonts, and `next/font` output isn't reachable there).

- `Fraunces-SemiBold.ttf`, `Fraunces-Italic.ttf` — Fraunces, © Undercase Type
- `DMMono-Regular.ttf` — DM Mono, © Colophon Foundry

Both families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Instantiated cuts as served by Google Fonts.
